# Evidencias conservadas

- pruebas_en_docker.txt: salida original de unittest en Windows PowerShell, 13 pruebas y OK. Codificación original UTF-16; se abre directamente en Bloc de notas.
- verificacion_docker/resultado.json: ocho comprobaciones de integración y estado PASS; backend Docker.
- integridad_datos.json: huellas SHA-256 de los JSON/CSV originales de medición y salidas de pruebas. Permite comprobar que el análisis no cambió la evidencia.

No hay salida de conformidad oficial. El archivo check_local.py es una prueba propia y no debe identificarse como el verificador del profesor.


## Capturas

La carpeta capturas/ conserva nueve imágenes originales, su índice y huellas SHA-256. El registro de IA reproduce las imágenes como evidencia de validación técnica, no como conversación con la herramienta.
